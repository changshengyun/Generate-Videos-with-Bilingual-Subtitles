# LyricCaptioner 中文使用说明与开发进度

## 1. 项目是什么

LyricCaptioner 是一款仅面向 Android 的本地优先视频字幕编辑 App，主要处理
5 分钟以内的短视频。目标流程是：

```text
导入视频 -> 识别英文语音或歌声 -> 上下文纠错 -> 生成中英双语字幕
-> 人工校对文字和时间 -> 预览 -> 烧录字幕并导出 MP4
```

项目目录：

```text
D:\DevEnv\Work\lyric-captioner-android
```

当前 Debug APK：

```text
app\build\outputs\apk\debug\app-debug.apk
```

## 2. 当前版本怎么使用

### 2.1 安装 App

连接已开启 USB 调试的 Android 手机，然后在项目根目录执行：

```powershell
.\gradlew.bat installDebug
```

也可以把 `app-debug.apk` 安装到手机。

### 2.2 导入视频

1. 打开 App。
2. 点击 `Import`。
3. 从手机文件选择器中选择视频。
4. 视频应不超过 5 分钟。
5. 导入后可以在页面顶部播放视频；已有字幕会按照播放器时间实时叠加预览。

### 2.3 生成字幕

页面会显示两项本地识别状态：

```text
Model: ready / missing
JNI: ready / missing
```

- 显示 `Generate Demo`：当前使用演示识别结果，不是真实 Whisper 识别。
- 显示 `Generate Local`：模型和 Whisper JNI 均已就绪，会运行真实本地识别。

点击 `Whisper Model` 可以选择本地 Whisper `.bin` 模型。模型会流式复制到
App 私有目录：

```text
files/models/ggml-base.en.bin
```

注意：导入模型只能解决模型文件缺失，不能代替 Whisper JNI `.so`。2026-07-10
已验证原生构建，当前 Debug APK 已打包 `arm64-v8a` 与 `x86_64` 的
`liblyriccaptioner_whisper.so`。导入模型后即可使用 `Generate Local`；实际识别
效果仍需连接真机验证。

### 2.4 导入已有字幕或歌词

- `Import SRT`：导入已有 SRT 字幕。
- `Lyrics`：导入原歌词后按顺序匹配现有字幕，并把不同文本作为纠错候选，不会直接覆盖识别结果。
- `Open Project`：打开以前保存的项目归档。

没有现成字幕时，点击 `Add Caption` 新增一条空字幕，直接填写英文和中文，调整时间后即可预览和导出。

也可以点击 `Paste Lyrics`，直接粘贴每行一句的英文歌词。App 会按视频总时长自动生成均分时间轴；这是最快的初稿方式，随后再手动调整关键句时间。

点击 `Translate` 可以把尚未填写中文的英文字幕批量翻译成中文。首次使用需要在 Wi-Fi 下下载 ML Kit 翻译模型，之后可离线使用。

### 2.5 编辑字幕

每条字幕支持：

- 修改英文字幕。
- 修改中文翻译。
- 起始时间前移或后移 0.1 秒。
- 结束时间前移或后移 0.1 秒。
- 选择英文纠错候选。
- 查看识别置信度。
- 对校对完成的字幕点击 `Confirm`。
- 点击 `Delete` 删除不需要的字幕。

时间调整会限制最短持续时间，并避免与相邻字幕重叠或超过视频总时长。

点击任意字幕卡，播放器会自动跳到该条字幕的起始位置，方便逐条校对。

### 2.6 调整字幕样式

`Subtitle style` 区域支持：

- `A- / A+`：减小或增大字幕字号。
- `Lower / Higher`：调整字幕距离画面底部的位置。

英文与中文使用不同颜色，导出时带阴影以提高可读性。

### 2.7 导出带字幕视频

1. 确认字幕文字和时间。
2. 点击 `Export`。
3. 在 Android 文件选择器中选择 MP4 保存位置和文件名。
4. App 使用 Media3 Transformer 重新编码视频。
5. 中英双语字幕会按时间轴烧录进画面。
6. 导出成功后点击 `Share`，可以通过系统分享生成的 MP4。

这里生成的不是假 URI。当前代码会创建真实的 H.264/AAC MP4 文件。

### 2.8 保存其他文件

- `SRT`：另存双语 SRT 字幕。
- `Save Project`：保存当前视频 URI、字幕、时间和样式配置。
- `Open Project`：恢复项目归档。

## 3. 如何构建项目

环境要求：

```text
JDK 17
Android SDK Platform 35
Gradle 8.9 Wrapper
Android NDK 27.3.13750724
CMake 3.22.1
```

测试并构建 Debug APK：

```powershell
.\gradlew.bat test assembleDebug
```

当前机器如果 Kotlin daemon 因临时目录权限失败，可以使用：

```powershell
.\gradlew.bat test assembleDebug -Pkotlin.compiler.execution.strategy=in-process
```

## 4. 项目主要结构

```text
app/src/main/java/com/example/lyriccaptioner/
├─ audio/          PCM 混音、16 kHz 重采样、WAV 写入
├─ captions/       字幕时间轴、SRT 解析和写出
├─ model/          编辑器、字幕、导出配置数据模型
├─ processing/     音频抽取、Whisper、翻译、视频导出管线
├─ project/        项目归档
├─ ui/             Compose 编辑界面和视频预览
├─ MainActivity.kt
└─ MainViewModel.kt
```

核心技术：

- Kotlin、Jetpack Compose
- Media3 ExoPlayer、Transformer、OverlayEffect
- Android MediaExtractor、MediaCodec
- ML Kit Translation
- whisper.cpp JNI 接口

## 7. 常见问题

### 为什么导入模型后仍显示 Demo？

模型文件和 JNI 是两个独立条件。模型导入成功但 APK 没有 Whisper JNI `.so`
时，不能执行本地 Whisper，App 会继续明确显示 Demo。

### 导出视频是真的文件吗？

是。App 会先使用 Media3 Transformer 生成临时 MP4，再复制到你在 Android
文件选择器中指定的位置。

### 为什么某一时间点没有显示字幕？

实时预览只会显示当前播放器时间落在 `startMs <= time < endMs` 范围内的字幕。
如果时间轴存在空隙，对应位置不会显示字幕。

### 英文歌曲能否 100% 还原原歌词？

不能保证。唱歌存在连读、弱读、伴奏干扰和发音变化。产品设计会保留置信度、
纠错候选和人工确认，不会把低置信度内容强行改成确定答案。

### 哪些本地文件不会同步到 GitHub？

`.gitignore` 已排除：

```text
local.properties
.gradle/
build/
app/build/
*.msi
*.msix
models/
app/src/main/assets/models/
ggml-*.bin
*.gguf
```

本地安装包、SDK 路径、构建产物和大型模型文件都不应提交或推送。

## 8. 构建 Whisper JNI

下载固定版本的官方 whisper.cpp 源码：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\setup-whisper-native.ps1
```

源码版本固定为：

```text
v1.9.1
```

源码下载目录 `third_party/whisper.cpp` 已被 `.gitignore` 排除，不会同步到
GitHub。安装 NDK 27.3.13750724 和 CMake 3.22.1 后执行：

```powershell
.\gradlew.bat assembleDebug -PenableWhisperNative=true
```

默认不传 `enableWhisperNative` 时仍可构建普通 APK，但 APK 内不会包含
`liblyriccaptioner_whisper.so`，因此会明确使用 Demo 识别。

2026-07-10 已执行 `assembleDebug -PenableWhisperNative=true`，并检查 APK 内容，
确认该原生构建开关生成的 APK 已包含两个 ABI 的 `liblyriccaptioner_whisper.so`。
